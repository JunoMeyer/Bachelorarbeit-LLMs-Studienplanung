# Bacheloarbeit-LLMs-Studienplanung
Analyse der Qualität von LLM-Outputs für die Studienplanung einer psychologischen Bachelorarbeit

## Inhalt

- `analysis.R`: R-Skript zur Berechnung der deskriptiven Statistiken und Häufigkeitstabellen
- `data/`: Datensatz der kodierten LLM-Outputs
- `results/`: durch das Skript erzeugte Ergebnistabellen
- `codebook.md`: Beschreibung der Variablen und Kodierungen

## Reproduzierbarkeit

Das Skript wurde mit R ausgeführt. Die verwendeten Paketversionen sind in `results/sessionInfo.txt` dokumentiert.

## Ausführung

1. Repository herunterladen oder klonen.
2. R-Projekt öffnen.
3. Benötigte Pakete installieren.
4. `analysis.R` ausführen.
